# 时光信笺

## 简介
“时光信笺”是一款简单易用、自由灵活、扩展性强、本地运行且无需联网的照片水印与边框工具。

## 由来
灵感源自网络上的“埋信仪式”——“寻一块地，埋一封信，寄给若干年后的自己”。将此刻心绪悉心封存，静待时光开启。
照片亦是如此。如果说书信是写给未来的文字独白，那么照片便是赠予岁月的无声诗篇。
愿我们都能将转瞬即逝的心绪，凝成一封封穿越时光的无声信笺。待到未来的某日，被你亲手拆开，与曾经的自己，温柔重逢，再忆彼时。
